# Покраска и Ремонт

Android-приложение для учёта заявок на покраску и ремонт. Заявки хранятся локально на устройстве в SQLite; сервер и регистрация не требуются.

## Возможности

- Создание заявок на покраску и ремонт с контактами клиента, датой и временем. Для покраски указывается цвет, для ремонта — описание проблемы.
- Просмотр всех заявок на главном экране и отдельных списков по типу.
- Редактирование данных заявки, отметка о выполнении и удаление.
- Статистика по заявкам в работе и выполненным заявкам каждого типа.

## Запуск

Откройте проект в Android Studio, дождитесь синхронизации Gradle и запустите модуль `app` на эмуляторе или устройстве с Android 13 (API 33) либо новее. Проект настроен на `compileSdk 36` и использует Gradle Wrapper.

## CRUD и хранение данных

`DatabaseHelper` создаёт базу `service.db` с таблицей `requests`. В ней хранятся ID, имя и телефон клиента, модель, цвет, дата, тип (`paint` или `repair`), статус и описание проблемы. `RequestDao` выполняет операции SQLite:

| Операция | Где используется |
| --- | --- |
| Create — добавление | Формы создания заявок на покраску и ремонт |
| Read — чтение | Главный экран, списки по типу, экран редактирования и статистика |
| Update — изменение | Сохранение правок и отметка «выполнено» |
| Delete — удаление | Главный экран и списки заявок |

Новая заявка получает статус «в работе». Данные остаются в локальной базе приложения между запусками. Текущая реализация `onUpgrade` пересоздаёт таблицу при смене версии схемы, поэтому перед обновлением `DATABASE_VERSION` нужна миграция, если важно сохранить существующие заявки.
